# Portfolio Starter (HTML/CSS/JS)

This is a simple portfolio scaffold you can deploy on GitHub Pages.

## Pages
- `index.html` (home)
- `cv.html` (digital CV)
- `modules.html` (module list)
- `modules/` (one page per module)
- `journal.html` (professional development journal)

## Deploy on GitHub Pages (quick)
1. Create a new GitHub repo, e.g. `portfolio`
2. Upload these files to the repo root
3. GitHub repo Settings → Pages → Deploy from branch → `main` / root
4. Your URL becomes `https://USERNAME.github.io/portfolio/`

Replace placeholders and add your real module pages, journal entries, and GitHub links.
